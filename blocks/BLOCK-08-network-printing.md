# Блок 08 — Прямая печать на IP-принтер

**Статус:** ⏳ запланировано
**Зависит от:** блок 03 (выполнен)
**Оценка:** половина сессии

---

## Цель

Печатать этикетки в один тап, без скачивания `.prn` и ручной отправки на принтер.

## Контекст

Сейчас `GET /api/warehouse/labels.prn` отдаёт файл, который кладовщик
скачивает и отправляет на принтер сам. В `WAREHOUSE-PLAN.md` это отмечено
как незакрытый пункт: «⏳ отправка ZPL напрямую на IP-принтер из приложения».

Профили принтеров уже есть — `store.settings["warehouse_printers"]`
(поля `name`, `width_mm`, `height_mm`, `format`, `copies`),
редактируются в настройках склада, отдаются через `GET /api/warehouse/printers`.

Генераторы готовы: `pdfreport.labels_zpl()` и `labels_epl()` с экранированием.

## Задачи

- [ ] Добавить в профиль принтера поля `host` и `port` (по умолчанию 9100)
- [ ] `POST /api/warehouse/print/network` — отправка ZPL/EPL сокетом на
      `host:port` (RAW/JetDirect), таймаут 5 секунд
- [ ] Кнопка «🖨 Печать на принтер» рядом с существующим скачиванием
- [ ] Понятные ошибки: недоступен, таймаут, отказ соединения
- [ ] `POST /api/warehouse/print/test` — тестовая этикетка для проверки связи
- [ ] Тесты с мок-сервером на localhost:9100

## Критерии приёмки

- [ ] Мок-сервер получает корректный ZPL, совпадающий с `labels.prn`
- [ ] Недоступный хост → **502** с внятным текстом, сервер не виснет
- [ ] Таймаут срабатывает за 5 секунд
- [ ] Печать пишется в журнал действий
- [ ] Только роль `admin` может менять `host`/`port`
- [ ] Регрессия: 20/20, 8/8, 23/23

## Риски безопасности

`host` задаёт пользователь — это классический **SSRF**. Обязательно:

- разрешать только приватные диапазоны (10/8, 172.16/12, 192.168/16, 127/8);
- запретить произвольные порты, кроме 9100 и 631;
- не возвращать клиенту тело ответа принтера.
