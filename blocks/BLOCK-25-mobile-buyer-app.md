## Отчёт Фазы 1 (11.09.2026)

### Что сделано

**Android-обёртка `mobile/android-wrapper/`** (по образцу проверенного `apk-build/android`):
- пакет `ru.telegramshop.shop`, versionName 1.0.0, versionCode 1, minSdk 23 (Android 6+), targetSdk 34;
- `MainActivity.java`: WebView витрины `/`, экран первого запуска с вводом адреса
  (или `BuildConfig.SHOP_URL` из `-PshopUrl=`), deep links `shop://setup?url=` /
  `shop://connect?url=` (мгновенное подключение) / `shop://install` (страница `/download/app`),
  ссылки только своего магазина открываются внутри, внешние — в браузере;
- мягкий **баннер обновления**: при подключении приложение сверяет свою версию с
  `GET /api/app/version` и предлагает скачать APK, если на сервере новее;
- экран ошибки сети с «Повторить»; долгое нажатие на экране → настройки подключения;
  выбор изображений в web-формах (ACTION_GET_CONTENT); cookies/DOM storage;
- без камеры/сканера/печати и без лишних разрешений (только INTERNET, ACCESS_NETWORK_STATE);
  иконки (индиговая shopping-bag, mipmap 5 dpi) закоммичены;
- подпись — **общий keystore со «Складом»** (решение владельца, Фаза 0).

**Сервер (`api.py`)**:
- `GET /download/app` — страница скачивания с QR-конфигуратором deep link
  (шаблон `site/templates/app_download.html`, JS `site/js/app-download.js`);
- `GET /api/app/version` — версия, `min_supported_version`, `download_url`, `package_id`,
  `deep_link_install` (используется обёрткой для update-check);
- `GET /api/app/version/qr.svg?mode=connect|setup|install&server=` — SVG-QR deep link;
- релизы ищутся по файлам `Shop-*.apk` / `Shop-*.aab` в `telegram-shop/apk|aab`
  (те же маунты `/apk/`, `/aab/`, что у складских), SHA-256 и размеры — на странице;
- `/download/app` добавлен в `sitemap.xml`, ссылка — в футер всех SSR-страниц.

**Сборка и CI**:
- `mobile/android-wrapper/build-apk.sh` — самодостаточная сборка (JDK17, SDK, Gradle 8.2.1
  в `~/.cache`, без sudo), результат `telegram-shop/apk/Shop-1.0.0-release.apk` + `.aab`;
- `ci-build-shop-apk.sh` — CI-обёртка (только Actions/push, защита от цикла, коммит артефактов
  в ветку), вызывается из `run-tests.sh` после складской сборки.

**Тесты**: `tests-block25.py` — 29 проверок (страница, JSON, QR, раздача APK при наличии
артефакта, sitemap, футер, security-заголовки, поведение без собранного APK).

### Ручные шаги владельца (после вливания PR)
1. Дождаться CI-сборки: артефакты `Shop-1.0.0-release.apk/.aab` появятся в репо автоматически.
2. Установить APK на телефон (Android 8/12/14), открыть витрину, пройти заказ до оплаты.
3. Проверить deep link: отправить себе `shop://connect?url=https://ваш-домен/` (или QR со страницы `/download/app`).
4. Проверить баннер обновления: собрать новую версию (поднять `APP_VERSION`/`APP_CODE` в `build-apk.sh`) — приложение предложит обновление.
