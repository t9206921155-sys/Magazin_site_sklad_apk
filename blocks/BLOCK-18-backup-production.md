# Блок 18 — Backup/restore production на тестовом VPS

**Статус:** ⏳ запланировано

## Цель
Настроить автоматическое резервирование и подтвердить восстановление на тестовом VPS.

## Задачи
- [ ] ежедневный SQLite backup с retention 7/30 дней;
- [ ] upload backup во внешнее хранилище;
- [ ] checksum и manifest;
- [ ] systemd timer/cron;
- [ ] dry-run restore;
- [ ] восстановление на отдельную базу;
- [ ] rollback текущей базы;
- [ ] уведомление об ошибке backup;
- [ ] screenshots каждой операции.

## Для VPS 1 vCPU / 1 GB / 10 GB

- [ ] включить swap 2–4 GB;
- [ ] не хранить backup-пакеты на VPS дольше операции;
- [ ] хранить фото и backup вне локального диска;
- [ ] ограничить размер логов и временных файлов.

## Приёмка

- [ ] backup создаётся автоматически;
- [ ] backup доступен после удаления локального файла;
- [ ] checksum совпадает;
- [ ] restore проходит на чистой копии;
- [ ] контрольные товары, заказы, пользователи и склады на месте.
