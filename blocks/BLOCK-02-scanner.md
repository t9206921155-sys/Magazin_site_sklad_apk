## Отчёт

**Выполнено:**

В коде и меню HID был помечен «Заглушка (stub)», но проблема оказалась не
в неполноте, а в **сломанной логике парсера** — четыре реальных дефекта:

1. **Мёртвая ветка.** `if (delta < 150 && delta > 5) {...} else {...}` —
   обе стороны выполняли идентичный код. Проверка скорости ни на что не
   влияла, ручной ввод человека попадал в буфер сканера.
2. **Склейка кодов.** Без Enter буфер не сбрасывался, следующий скан
   дописывался к предыдущему.
3. **Сканеры без Enter-суффикса** не работали вовсе.
4. **Двойное срабатывание** при дребезге — в режиме «Продажа» это списало
   бы товар дважды.

Переписано: отсечка ручного ввода по межсимвольному интервалу (`FAST_MS = 35`),
сброс буфера по паузе, отправка по тишине для сканеров без Enter
(`IDLE_FLUSH = 120`) с переключателем в UI, дедупликация (`DEDUP_MS = 700`),
отсечка шума короче 4 символов, живой лог принятых кодов, показ текущего
режима (Поиск / Приёмка / Продажа / Инвентаризация).
