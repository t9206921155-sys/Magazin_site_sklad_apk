# Блок 19 — Внутренняя CRM и общение сотрудников

**Статус:** ⏳ запланировано

## Цель
Создать закрытый рабочий раздел для сотрудников магазина и склада.

## MVP

- [ ] раздел `/crm/` только после авторизации;
- [ ] сотрудники, роли и подразделения;
- [ ] задачи с ответственным, статусом, сроком и приоритетом;
- [ ] внутренние комментарии и обсуждения задач;
- [ ] личные и групповые чаты сотрудников;
- [ ] прикрепление товаров, заказов и складских операций;
- [ ] уведомления о новых сообщениях и задачах;
- [ ] журнал действий и поиск;
- [ ] offline-фолбэк для черновиков сообщений;
- [ ] запрет доступа сотрудника к чужим подразделениям при необходимости.

## Безопасность

- [ ] отдельные CRM permissions;
- [ ] admin/manager/worker/read-only;
- [ ] аудит удаления сообщений и задач;
- [ ] ограничения файлов и типов вложений;
- [ ] не показывать клиентам внутреннюю переписку.

## Приёмка

- [ ] два сотрудника видят общий чат в реальном времени;
- [ ] задача назначается и переводится по статусам;
- [ ] комментарии сохраняются после перезапуска;
- [ ] складской документ открывается из CRM;
- [ ] сотрудник без права не видит закрытый раздел;
- [ ] API и UI покрыты тестами и ручными screenshots.
