# Блок 11 — Проверка на реальном железе

**Статус:** ⛔ заблокировано — нужен физический доступ к устройствам
**Зависит от:** блоки 02, 03, 04 (выполнены)
**Исполнитель:** владелец проекта, не агент

---

## Почему заблокировано

Всё перечисленное покрыто автотестами и проверено на моках, но подтвердить
поведение реального оборудования из песочницы невозможно. Это единственный
блок, который агент выполнить не может.

## Чек-лист для проверки на месте

### Bluetooth/ТСД-сканер (блок 02)

- [ ] Zebra DS3678 или Атол SB2108 в HID-режиме
- [ ] Открыть склад → «📶 Bluetooth / ТСД (HID)» → включить приём
- [ ] Сканировать EAN-13 — код подставляется целиком, без потери символов
- [ ] Сканировать два кода подряд — не склеиваются
- [ ] Проверить сканер **без** Enter-суффикса — снять галочку «Сканер шлёт Enter»
- [ ] Сканировать один код дважды быстро — второй раз игнорируется
- [ ] Режим «Продажа»: остаток уменьшается **один** раз, не два

Если тайминги не совпадут, крутить константы в `warehouse/app.js`:
`FAST_MS = 35`, `IDLE_FLUSH = 120`, `DEDUP_MS = 700`.

### Термопринтер (блок 03)

- [ ] Zebra (ZPL): скачать `.prn`, отправить на принтер, проверить читаемость
      штрих-кода сканером
- [ ] Eltron/ОВЕН (EPL): то же самое
- [ ] Товар с `^` или `~` в названии — этикетка печатается целиком,
      принтер не отменяет очередь
- [ ] Ценники: размер шрифта читаем с расстояния, QR сканируется
- [ ] Проверить размеры этикеток из профилей принтеров

### Офлайн-режим (блок 04)

- [ ] Открыть склад на телефоне, включить авиарежим
- [ ] Изменить остаток — появляется «📴 Нет сети · в очереди: 1»
- [ ] Выключить авиарежим — операция уходит, счётчик обнуляется
- [ ] Проверить на **iOS/Safari**: Background Sync не поддерживается,
      очередь должна уйти при следующем открытии приложения
- [ ] Убедиться, что после переподключения список обновился (не из кэша)

### APK (блок 01, ранее)

- [ ] Установить `Sklad-1.0.6-release.apk` на Android 6.0+
- [ ] Экран настроек подключения, deep link `sklad://setup`
- [ ] QR-подключение, сканирование камерой внутри APK
- [ ] Мультивыбор фото

### 1С (блок 04)

- [ ] Выгрузка остатков из боевой 1С через `POST /1c/stock`
- [ ] Проверить `not_found` — коды, которых нет на витрине
- [ ] Убедиться, что названия товаров не затёрлись
