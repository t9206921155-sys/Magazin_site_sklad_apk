# Блок 15 — Production security и observability

**Статус:** ⏳ запланировано

## Цель
Сделать production-эксплуатацию безопасной и диагностируемой.

## Задачи
- [ ] аудит CORS, trusted hosts, cookies и security headers.
- [ ] ротация токенов и проверка срока действия секретов.
- [ ] структурированные логи без токенов и паролей.
- [ ] метрики ошибок API, времени ответа и доступности storage.
- [ ] уведомление при падении сервера, заполнении диска и неудачном backup.
- [ ] rate limit для login, 1С и публичных endpoint.

## Приёмка
- [ ] секреты отсутствуют в логах.
- [ ] health/metrics не раскрывают чувствительные данные.
- [ ] security smoke и regression проходят.
