# Блок 14 — Backup, restore и MySQL/MariaDB

**Статус:** ⏳ запланировано

## Цель
Подтвердить, что данные можно восстановить, а MySQL/MariaDB на VPS подключается без потери данных.

## Задачи
- [ ] атомарный SQLite backup через backup API.
- [ ] upload backup в отдельный bucket.
- [ ] restore в временную БД.
- [ ] export/import SQLite → MySQL/MariaDB.
- [ ] проверка товаров, заказов, складов, пользователей и настроек.
- [ ] rollback и dry-run миграции.
- [ ] инструкция для phpMyAdmin.

## Приёмка
- [ ] восстановление проходит на чистой среде.
- [ ] контрольные суммы и количество записей совпадают.
- [ ] ошибки миграции не повреждают исходную БД.
