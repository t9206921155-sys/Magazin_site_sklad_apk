# Блок 21 — AI-видео и контент-агенты

**Статус:** ⏳ запланировано

## Цель
Генерировать короткие вертикальные ролики товара для Telegram, VK, Instagram и TikTok с ручным подтверждением публикации.

## Задачи
- [x] формирование промта из объявления и экспорт данных товара;
- [x] формирование промта из объявления и экспорт данных товара;
- [ ] pipeline: фото товара → сценарий → voiceover → видео 9:16 → preview;
- [ ] шаблоны для 10–30 секунд и 30–60 секунд;
- [ ] субтитры, цена, состояние, CTA и UTM;
- [ ] отдельные agents: copywriter, storyboard, media renderer, compliance checker;
- [ ] внешний AI provider через adapter, без жёсткой привязки к одному API;
- [ ] локальный fallback: slideshow из фото без AI-видео;
- [ ] очередь задач и ограничение стоимости;
- [ ] ручное подтверждение перед публикацией;
- [ ] watermark/брендинг и safe-area для каждой площадки;
- [ ] хранение исходников и готовых роликов в Object Storage;
- [ ] запрет публикации без проверки прав на фото и музыку.

На текущем этапе генерация видео не выполняется на VPS. Система формирует prompt/package и экспортирует его во внешний сервис. Результат можно импортировать обратно по callback или вручную.

## Приёмка

- [ ] ролик генерируется из карточки без блокировки API;
- [ ] сбой AI provider не ломает магазин;
- [ ] готовый ролик можно скачать и отправить вручную;
- [ ] публикация выполняется только после approve;
- [ ] затраты и provider фиксируются в журнале;
- [ ] screenshots preview и публикации.
