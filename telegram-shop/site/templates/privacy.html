Политика конфиденциальности мобильного приложения «Склад»

Настоящая политика описывает, какие данные может обрабатывать сервис {{ shop_name }} при использовании сайта, раздела /warehouse/ и Android-приложения «Склад».

1. Какие данные используются

  • учётные данные пользователя склада для входа в систему;
  • данные о товарах, остатках, ценах, фотографиях и заказах, которые пользователь сам вносит в систему;
  • технические данные, необходимые для работы сервиса: cookies, local storage, адрес подключённого сервера и журналы ошибок.

2. Для чего это нужно

  • для авторизации и безопасного доступа к складу;
  • для управления товарами, публикацией, заказами и складскими операциями;
  • для загрузки фотографий, печати этикеток и синхронизации между сотрудниками.

3. Как работает Android-приложение

Приложение «Склад» является Android-обёрткой над веб-интерфейсом /warehouse/. Оно сохраняет адрес подключённого сервера на устройстве, может открывать deep link вида sklad://setup и sklad://connect, а также передавать выбранные пользователем файлы в интерфейс склада.

4. Передача данных третьим лицам

Данные не передаются третьим лицам автоматически, кроме случаев, когда это необходимо для работы подключённых сервисов магазина: облачного хранения, платёжной инфраструктуры, push-уведомлений или других интеграций, настроенных владельцем проекта.

5. Хранение и безопасность

Данные хранятся на сервере, который использует владелец магазина. Пользователь проекта обязан самостоятельно обеспечить безопасность хостинга, резервное копирование, контроль доступа сотрудников и корректную настройку HTTPS.

6. Контакты

Для обращений по вопросам конфиденциальности и поддержки укажите рабочий email разработчика или владельца магазина на странице публикации RuStore. Эту политику рекомендуется адаптировать под реальные юридические данные проекта перед публичной публикацией приложения.
