Установка по шагам

короткая инструкция для сотрудника склада
1

Скачайте APK

Откройте файл на Android и разрешите установку из этого источника.

2

Подключите сервер

Введите адрес вручную или откройте ссылку sklad://connect?url=... прямо на телефоне.

3

Войдите в склад

Используйте учётку администратора или сотрудника, сохранённую для вашей общей базы.

4

Работайте с товарами

Фото, штрих-коды, этикетки, публикация на витрину, облако и синхронизация уже подключены.

Где лежат исходники Android-обёртки

чтобы быстро найти нужные файлы в репозитории

Основные пути

  • telegram-shop/apk-build/android/app/src/main/java/ru/telegramshop/sklad/MainActivity.java — WebView-обёртка, deep link, выбор файлов, экран подключения
  • telegram-shop/apk-build/android/app/src/main/AndroidManifest.xml — permissions, activity, custom scheme sklad://
  • telegram-shop/apk-build/android/app/build.gradle — package name, versionCode, versionName, signing config
  • telegram-shop/apk-build/rebuild-apk.sh — пересборка релизных Android-артефактов
  • telegram-shop/apk-build/README-APK.md — инструкция по сборке и установке
  • telegram-shop/warehouse/ — само PWA-приложение склада, которое открывается внутри APK

Что скачать / куда выкладывать

  • telegram-shop/apk/ — готовые APK-файлы
  • telegram-shop/aab/ — bundle для RuStore / Google Play
  • /download/android — лендинг загрузки Android-сборок
  • /api/releases/android — JSON с метаданными по APK/AAB и ссылками подключения
