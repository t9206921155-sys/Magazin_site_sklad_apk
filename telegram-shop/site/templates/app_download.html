📱 Android-приложение магазина

Каталог, корзина и заказы — отдельным приложением на телефоне

«Магазин» — лёгкая Android-обёртка над витриной: открывает сайт в WebView, сохраняет адрес магазина, понимает deep link shop://connect, показывает баннер при выходе новой версии и открывает внешние ссылки в браузере, не теряя корзину.

ℹ️ Как это работает

Внутри приложения

  • Ссылки вашего магазина открываются внутри приложения, внешние — в браузере.
  • Адрес витрины можно сменить без переустановки (долгое нажатие на экране → настройки).
  • Новая версия APK предложит обновиться мягким баннером.
  • Складское приложение «Склад» живёт отдельно: /download/android.

Установка по шагам

короткая инструкция для покупателя
1

Скачайте APK

Откройте файл на Android и разрешите установку из этого источника.

2

Сканируйте QR или откройте deep link

Подключение сработает через shop://connect?url=... или shop://setup?url=....

3

Покупайте

Каталог, корзина, оплата и статусы заказов — те же, что на сайте.

4

Обновляйтесь

Когда выйдет новая версия, приложение покажет баннер со ссылкой на APK.

Где лежат исходники

чтобы быстро найти нужные файлы в репозитории

Основные пути

  • mobile/android-wrapper/app/src/main/java/ru/telegramshop/shop/MainActivity.java — WebView-обёртка витрины, deep links, баннер обновлений
  • mobile/android-wrapper/app/src/main/AndroidManifest.xml — permissions, activity, схема shop://
  • mobile/android-wrapper/app/build.gradle — пакет ru.telegramshop.shop, версия, подпись
  • mobile/android-wrapper/build-apk.sh — пересборка релизных артефактов
  • mobile/ANDROID-APP-TZ.md — полное ТЗ и план развития (Фазы 2–6, React Native)

Что скачать / API

  • telegram-shop/apk/ — готовые APK-файлы (Shop-*)
  • /download/app — эта страница загрузки
  • /api/app/version — JSON с версией и ссылкой на APK
  • /api/app/version/qr.svg — SVG-QR для deep link подключения
