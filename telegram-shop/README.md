# 🛍 Telegram Shop — маркетплейс + SEO-сайт + Telegram Mini App + склад/PWA/APK

Полноценная e-commerce платформа: маркетплейс и магазин в Telegram (бот + Mini App),
SEO-сайт на серверном рендеринге, витрины продавцов, админ-панель (CMS), мобильный склад
(PWA/APK), оплата (карты/СБП, крипта, Telegram Stars), доставка (СДЭК, 5POST, Яндекс),
промокоды, безопасная сделка, чат покупатель↔продавец, бесплатная доставка,
брошенная корзина, рассылки, аналитика, рекомендации, ИИ (описания, реклама, поиск
аналогов), автогенерация баннеров и видеороликов, автопостинг в Telegram/VK,
синхронизация с 1С.

**📋 План дальнейшего развития (SEO-продвижение, ИИ-видео, реклама, маркетплейсы) —
в файле `PLAN.md` — на согласование.**

## Что где находится

| Адрес | Что это |
|---|---|
| `/` | **Сайт (SSR, SEO)**: продающая главная, каталог, карточки товаров, рекомендации |
| `/catalog` | Каталог с категориями и поиском (индексируется) |
| `/p/{id}` | Карточка товара: JSON-LD Product, OG-разметка, «Поделиться», рекомендации |
| `/shop` | Приложение (SPA): корзина, оформление, оплата, «Мои заказы» (noindex) |
| `/app` | Mini App для Telegram (открывается кнопкой в боте) |
| `/admin` | Админ-панель (CMS). Пароль — `ADMIN_PASSWORD` в `.env` (по умолчанию `admin123`) |
| `/sitemap.xml`, `/robots.txt` | Карта сайта и правила индексации (автоматически) |
| `/api/...`, `/1c/...`, `/webhook/...` | API витрины, обмен с 1С, вебхуки платёжек |
| `/media/...` | Сгенерированные баннеры и видеоролики |

## Быстрый старт

```bash
cd telegram-shop
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN и ADMIN_IDS
python bot.py
```

Откройте http://localhost:8000 — сайт. `/app` — Mini App. `/admin` — админка.
Без BOT_TOKEN бот отключён, но сайт и админка работают (превью-режим).

**Docker (продакшен):**
```bash
docker compose up -d --build      # сайт на :8000, данные в ./data
./scripts/backup.sh               # бэкап data/ + .env (хранит 14 копий)
```

Для Telegram нужен HTTPS: `cloudflared tunnel --url http://localhost:8000`,
адрес — в `WEBAPP_URL` в `.env`. Режим бота: `BOT_MODE=polling|webhook`.

## 🌐 Сайт и SEO

- **Современный продающий дизайн**: hero, преимущества, бейджи/скидки, анимации,
  адаптив (десктоп/планшет/мобильный, мобильное меню), семантический HTML5.
- **SSR для поисковиков**: главная, каталог, карточки товаров рендерятся на сервере
  (приложение корзины живёт в `/shop` с noindex — дублей нет).
- **SEO-пакет**: уникальные title/description, Open Graph + Twitter Cards, JSON-LD
  (Organization, Product с ценой/наличием, BreadcrumbList), sitemap.xml, robots.txt,
  canonical, SEO-тексты на страницах.
- **Рекомендации**: похожие товары, «с этим покупают» (анализ заказов), хиты продаж,
  «вы недавно смотрели».

## 🤖 ИИ-модуль (админка → Настройки → ИИ)

OpenAI-совместимый API (OpenAI, DeepSeek, OpenRouter…): в карточке товара кнопки
- **«ИИ: описание и SEO»** — продающее описание + SEO-заголовок + meta description;
- **«ИИ: реклама»** — пост для соцсетей, хештеги, слоган, сценарий ролика;
- **«ИИ: аналоги в интернете»** — поиск похожих товаров (Tavily API; без ключа —
  ссылки на Яндекс.Маркет/Ozon/WB/AliExpress по сгенерированному запросу).

## 🖼 Медиа-генератор (без внешних сервисов)

- **Баннеры**: 1080×1080 (пост) и OG 1200×628 — фото, название, цена, скидка, CTA;
- **Видеоролики**: 1080×1080 mp4, зум + титры + цена (ffmpeg, ~30 сек на ролик);
- Кнопки «🖼 Баннер» и «🎬 Видео» в таблице товаров, результат — по `/media/...`.

## 📣 Автопостинг (админка → Настройки → Автопостинг)

- Telegram-канал (бот — админ канала): фото + описание + цена + ссылка;
- VK-группа (access token + id): запись с фото;
- Переключатель «автопостинг новых товаров» — при создании товара пост уходит
  во все включённые каналы (из админки и из бота `/admin`);
- Кнопки «Поделиться» (VK/Telegram/WhatsApp/OK) на каждой карточке товара.

## 📌 Avito (админка → Настройки → Avito)

Два канала выкладывания товаров на Avito:

1. **REST API** — создание, обновление и закрытие объявлений (нужна заявка на доступ
   к API в кабинете Avito → client_id/client_secret):
   - кнопки «📌 Avito» / «🔄 Avito» / «✕ Avito» у каждого товара в админке;
   - пакетная выгрузка «все товары без объявлений»;
   - категорию можно выбрать из списка прямо в админке (кнопка «Категории»);
   - фото загружаются напрямую (multipart), публичный URL не обязателен;
   - статус и ссылка на объявление сохраняются в карточке товара;
   - автовыкладка новых товаров (переключатель).
2. **Автозагрузка по XML-фиду** — `/avito/autoload.xml?key=…`: ссылка добавляется
   в кабинете Avito как источник автозагрузки, Avito сам забирает каталог
   по расписанию. API-заявка не нужна. Для фото в фиде нужен публичный WEBAPP_URL.

## 📱 Мобильный склад (PWA → APK)

Приложение **«Склад»** — `/warehouse`: учёт товаров с телефона, устанавливается
на Android как приложение («Добавить на главный экран», fullscreen + офлайн-кэш).

- **Фото до 20 шт** из камеры, галереи или по URL из интернета;
- Внутренний **артикул**, **штрих-код**, наименование, **место хранения**, **владелец**,
  количество, цена, **сумма** (автоматически);
- Статус **«выставлено на витрину»** — переключатель; снятые с витрины скрываются
  из каталога сайта и Mini App;
- **🤖 ИИ-генерация** (бесплатные OpenAI-совместимые API: Groq, Gemini, OpenRouter free,
  GigaChat — настройки в админке → ИИ): название (3 варианта), текст объявления,
  пост для Telegram-канала;
- **📷 Камера-сканер** штрих-кодов и QR (BarcodeDetector: EAN/Code-128/QR) для поиска товара; в Android APK камера запрашивается нативно через WebView, а при нестабильном BarcodeDetector включается fallback на встроенный Android scanner;
- **🖨 Печать наклеек**: PDF с Code-128, артикулом, местом и владельцем — по одному
  товару или пачкой через чекбоксы;
- **✏️ Массовое редактирование**: чекбоксы → «Изменить» — цена, закупочная цена,
  место, владелец, категория, остаток, витрина, наличие — для всех выбранных сразу;
- **🔔 Push-уведомления** (Web Push/VAPID): новые заказы и оплаты на телефон;
  включение и тестовое уведомление в ⚙️; работают на HTTPS-домене;
- **⚡ Быстрый вход**: PIN на устройстве (работает везде, включая APK) и биометрия
  WebAuthn (отпечаток/лицо в Chrome/Safari на HTTPS) — настройка в ⚙️ → Быстрый вход;
- Поиск по артикулу, ШК, названию, месту, владельцу;
- **Единая облачная база для нескольких пользователей**: учётные записи с ролями
  (администратор/сотрудник), вход со своего устройства — все видят одни товары и фото
  мгновенно; **журнал операций** (кто что сделал), **индикатор синхронизации**
  «☁️ единая база · N товаров · синхронизировано ЧЧ:ММ:СС» с автопроверкой каждые 30 сек;
- **Наклейки под разные термопринтеры**: профили принтеров (название, размер этикетки,
  формат, копии); форматы **PDF** (любой принтер), **ZPL** (Zebra .prn) и **EPL**
  (Eltron/ОВЕН .prn); печать одного товара или пачки через чекбоксы;
- **☁️ Облако на выбор — 3 провайдера** (⚙️ Настройки → Облако):
  **S3** с готовыми пресетами российских провайдеров — Selectel, Cloud.ru, VK Cloud,
  Яндекс Объектное хранилище, MinIO (endpoint и регион подставляются автоматически,
  подсказка, где взять ключи; свои значения можно ввести вручную),
  **Supabase** (REST: каталог + Storage) и **MySQL/MariaDB** (база каталога, фото — в S3-бакете).
  «Проверить подключение», «Синхронизировать» (каталог + все фото) и «⬇️ Из облака»
  (восстановление каталога). Таблица MySQL создаётся автоматически при первом push;
- **🖼 Фото подтягиваются с облака**: после синхронизации сохраняется маппинг
  локальный путь → CDN-URL (`cloud_state`), и приложение отдаёт облачные ссылки —
  быстрая загрузка на любых устройствах. Переключатель «Подтягивать фото с облака»;
  при выключении — автоматический fallback на локальные файлы;
- **⚡ Автосинхронизация при сохранении**: включите — и каждое сохранённое фото
  сразу уходит в облако (фоновая задача), статус облака (сколько фото, когда
  синхронизировано) виден в настройках;
- **📣 Публикация в соцсети**: кнопка на каждом товаре — публикация в Telegram-канал
  и VK (каналы настраиваются в приложении); чекбокс «опубликовать при создании»;
  токены VK и ключи Avito — в админ-панели сайта;
- **⚙️ Расширенные настройки в приложении**: облако, автопубликация, профили
  принтеров (добавление/редактирование/удаление), смена своего пароля,
  запоминание логина на устройстве, экспорт склада в Excel.

## 🏪 Маркетплейс: продавцы и витрины

Площадка превращается в маркетплейс по модели Avito/Ozon:

- **Регистрация продавцов** — страница `/become-seller` или команда `/seller` в боте
  (название, телефон; подтверждение админом или автоматически — настройка в админке);
- **Своя витрина у каждого** — `/seller/{slug}`: название, описание, товары, SEO-страница;
- **Личный кабинет продавца** — `/seller` (вход по ключу): товары CRUD с фото,
  свои промокоды, заказы, статистика, баланс и запросы на выплату;
- **Комиссия площадки** — настраивается админом глобально (по умолчанию 15%)
  и индивидуально для каждого продавца; после оплаты заказа доля продавца
  автоматически зачисляется на его баланс, площадка получает свою комиссию;
- **Тарифы, настраиваемые админом** — админка → 💰 Тарифы: лимиты объявлений/фото/
  ИИ/промокодов по планам продавцов и склада, цены услуг продвижения, комиссия,
  срок холда. Лимиты применяются автоматически (TARIFFS.md);
- **Безопасная сделка (холд средств)** — оплата зачисляется в `held_balance`,
  размораживается при статусе «доставлен» или автоматически через N дней;
  отмена заказа возвращает холд; ручная разморозка в админке;
- **Чат покупатель↔продавец** — на сайте (панель на товаре), в Mini App
  (💬 в шапке и на карточке), в кабинете продавца («Сообщения»); счётчики
  непрочитанных, уведомление продавцу в Telegram;
- **Верификация продавцов** — заявка (ИНН/ФИО/фото документа) → подтверждение
  админом → бейдж ✅ «проверенный продавец» на витрине и в карточке товара;
- **Состояние товара** (новое/б/у/с дефектами) с бейджами и фильтром + **параметры**
  (бренд, размер, цвет…) — в админке, кабинете продавца, на карточке товара
  (schema.org itemCondition/additionalProperty);
- **Подкатегории с ЧПУ**: `/catalog/{категория}/{подкатегория}` (транслитерация),
  свои SEO-заголовки и тексты — админка → 🗂 Каталог; в sitemap;
- **Умный поиск**: опечатки (Левенштейн), синонимы, ранжирование, автодополнение;
- **Избранное** ❤: на сайте (страница `/favorites`) и в Mini App;
- **Выплаты** — продавец запрашивает сумму, админ выплачивает (кнопка в админке →
  Продавцы, история хранится); при отмене заказа начисления снимаются;
- **Уведомления** — продавцу в Telegram о новых заказах на его товары
  (при привязке Telegram в регистрации через бота);
- **Каталог** — товары всех продавцов в общем каталоге с указанием продавца,
  фильтр `?seller=slug`; заблокированные продавцы скрываются автоматически;
- Админ-панель → **🏪 Продавцы**: одобрение/блокировка, комиссия, балансы, выплаты.

**Управление и отчёты для владельца площадки:**

- **📈 Отчёт по комиссиям за период** (админка → Продавцы): выберите даты — получите
  продажи, комиссию площадки и суммы к выплате по каждому продавцу + итоги
  (включая прибыль площадки с учётом выплат). Экспорт в **CSV и PDF** (отчёт
  с таблицей, выплатами и прибылью — генератор на reportlab, кириллица);
- **Подтверждение выплат**: продавец запрашивает сумму → заявка в админке →
  кнопка «✅ Подтвердить выплату»;
- **📧 Email-уведомления продавцам** (SMTP настраивается в админке → Настройки →
  Маркетплейс): о новом заказе, о его оплате, об одобрении витрины и о проведённой выплате.
  Без SMTP письма просто не отправляются;
- **🔔 Telegram-уведомления продавцам**: о новом заказе на их товары и при каждой
  оплаченной продаже («💰 заказ оплачен — средства на балансе»).

**🚀 План развития в лёгкого конкурента Avito для б/у вещей** — `MARKETPLACE-PLAN.md`:
подкатегории, умный поиск, фильтры, фото-галереи, чат, безопасная сделка, рейтинги,
продвижение и монетизация — дорожная карта на согласование.
