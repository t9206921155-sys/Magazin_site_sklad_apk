# 🧭 Инструкция для владельца / администратора

Это практическая инструкция именно для владельца проекта: что и где заполнять, чтобы запустить склад, APK, витрину, облако и публикации.

## 1. Что нужно подготовить заранее

Минимально:
- сервер или VPS
- домен с HTTPS
- доступ к GitHub-репозиторию
- Telegram bot token
- ваш Telegram ID

Дополнительно по желанию:
- S3 / Selectel / Cloud.ru / VK Cloud / Яндекс Object Storage / MinIO
- MySQL / MariaDB или Supabase
- ключ ИИ-провайдера
- доступы VK / Avito / платёжных систем

## 2. Что заполнить в `.env`

Файл: `telegram-shop/.env`

Минимальные поля:

```env
BOT_TOKEN=ваш_бот_токен
ADMIN_IDS=ваш_telegram_id
ADMIN_PASSWORD=сильный_пароль_для_admin
WEBAPP_URL=https://ваш-домен
PAYMENT_PROVIDER=test
BOT_MODE=polling
HOST=0.0.0.0
PORT=8000
```

Что куда вписывать:

- `BOT_TOKEN` — токен от BotFather
- `ADMIN_IDS` — ваш Telegram ID, можно несколько через запятую
- `ADMIN_PASSWORD` — пароль для входа в `/admin`
- `WEBAPP_URL` — публичный домен проекта, без `/admin`, например `https://shop.example.com`
- `PAYMENT_PROVIDER` — `test`, пока не настроили боевую оплату
- `BOT_MODE` — `polling`, если не хотите сразу настраивать webhook

## 3. Как задеплоить

Из корня репозитория:

```bash
./deploy/deploy.sh --domain https://ваш-домен --expected-version 1.0.5
```

Если хотите вручную:

```bash
git fetch origin
git checkout arena/continue-marketplace-content
git pull --ff-only origin arena/continue-marketplace-content
cd telegram-shop
pip install -r requirements.txt
cd ..
docker compose down || true
docker compose build --no-cache
docker compose up -d
```

## 4. Что проверить сразу после деплоя

Откройте:
- `https://ваш-домен/`
- `https://ваш-домен/admin`
- `https://ваш-домен/warehouse/`
- `https://ваш-домен/download/android`
- `https://ваш-домен/download/android/rustore`
- `https://ваш-домен/privacy`

Или выполните:

```bash
./telegram-shop/scripts/post_deploy_smoke_check.sh https://ваш-домен 1.0.5
```

## 5. Что настроить в админке первым делом

Зайдите в `/admin` и проверьте:

1. **Основные данные магазина**
   - название магазина
   - тексты
   - контакты
   - ссылки на соцсети

2. **Продажи / оплата**
   - пока можно оставить `test`
   - позже подключить ЮKassa / Т-Банк / CryptoBot / Stars

3. **Доставка**
   - самовывоз
   - курьер
   - почта
   - при необходимости СДЭК / 5POST / Яндекс

4. **ИИ**
   - API URL
   - API key
   - модель

5. **Автопостинг / соцсети**
   - Telegram channel
   - VK group id
   - токены

6. **Avito**
   - client_id
   - client_secret
   - включение API или XML-фида

## 6. Как настроить склад

Откройте `https://ваш-домен/warehouse/`.

Сделайте по порядку:

1. войдите как администратор склада;
2. создайте пользователей `worker`;
3. создайте 2–3 тестовых товара;
4. проверьте фото, цену, остаток, артикул, штрих-код;
5. проверьте включение/отключение товара на витрине;
6. проверьте печать и сканер.

## 7. Как подключить APK склада

Файлы релиза:
- `telegram-shop/apk/Sklad-1.0.5-release.apk`
- `telegram-shop/aab/Sklad-1.0.5-release.aab`

Для сотрудников используйте APK.

### Что сказать сотруднику

Пусть сотрудник:
1. установит APK;
2. введёт адрес:

```text
https://ваш-домен/warehouse/
```

3. войдёт под выданным логином и паролем.

### Быстрое подключение

Можно вместо ручного ввода отправить:

```text
sklad://connect?url=https://ваш-домен/warehouse/
```

Или дать страницу:
- `https://ваш-домен/download/android`

## 8. Как подключить облако для картинок

Откройте:
- `/warehouse/` → `⚙ Настройки` → `Облако`

### Рекомендуемый вариант

Для большинства случаев:
- каталог оставить на сервере проекта;
- фото вынести в S3;
- включить облачную отдачу фото;
- включить автосинхронизацию при необходимости.

### Что куда вписывать для S3

В поля облака:
- **Provider / Preset** — выбрать провайдера
- **Endpoint** — URL S3 endpoint
- **Access Key** — ключ доступа
- **Secret Key** — секретный ключ
- **Bucket** — имя bucket
- **Region** — регион

После этого:
1. нажать `Проверить подключение`
2. нажать `Синхронизировать`
3. включить `Подтягивать фото с облака`
4. при желании включить `Автосинхронизация при сохранении`

## 9. Как подключить внешний MySQL / MariaDB

В том же разделе `Облако` выберите `MySQL / MariaDB`.

Заполните:
- **Host** — адрес БД
- **Port** — обычно `3306`
- **User** — логин БД
- **Password** — пароль
- **Database** — имя базы
- **Table** — обычно `products`

Дальше:
1. сохранить
2. проверить подключение
3. синхронизировать при необходимости

Важно: APK к MySQL напрямую не подключается.

## 10. Как подключить Supabase

Если используете Supabase, заполните:
- **URL** — адрес проекта Supabase
- **Key** — ключ доступа
- **Bucket** — bucket для фото

Дальше:
1. сохранить
2. проверить подключение
3. синхронизировать каталог и фото

## 11. Как создавать товары правильно

Рекомендуемый минимум для каждой карточки:
- название
- фото
- цена
- остаток
- категория
- артикул или штрих-код
- место хранения

Чтобы товар вышел на сайт:
- он должен быть в наличии
- у него должен быть включён показ **на витрине**

## 12. Как генерировать тексты и объявления

### В складе
Для товара можно генерировать:
- название
- описание
- пост для публикации

### В админке
Можно генерировать:
- SEO
- рекламу
- аналоги
- баннеры
- видео

Для этого сначала заполните в админке настройки ИИ:
- API URL
- API key
- модель

## 13. Как включить публикацию на каналы

### Telegram / VK
В настройках публикации заполните:
- канал Telegram
- ID группы VK
- токены доступа

После этого:
- можно публиковать вручную у товара;
- можно включить автопубликацию новых товаров.

### Avito
Есть 2 режима:

1. **API** — нужны `client_id` и `client_secret`
2. **XML feed** — используется URL `/avito/autoload.xml?key=...`

## 14. Как проверить Android-часть

Нужно проверить руками:
- установка APK
- вход сотрудника
- открытие списка товаров
- фото с камеры
- сканер
- deep link
- QR onboarding
- native fallback scanner
- экран обновлений APK

## 16. Минимальный идеальный порядок для владельца

1. заполнить `.env`
2. задеплоить проект
3. проверить сайт, админку и склад
4. создать сотрудников
5. добавить тестовые товары
6. проверить APK
7. подключить облако для фото
8. настроить ИИ
9. настроить Telegram / VK / Avito
10. проверить RuStore-страницу
11. подготовить финальные скриншоты
12. публиковать AAB или делать merge в `main`
