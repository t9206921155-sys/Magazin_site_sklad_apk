# ⚡ Первый запуск за 15 минут

Самый короткий путь, чтобы поднять проект, открыть склад и подключить APK.

## 1. Задеплойте проект

Из корня репозитория:

```bash
./deploy/deploy.sh --domain https://example.com --expected-version 1.0.6
```

Если домена ещё нет — можно сначала локально:

```bash
cd telegram-shop
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## 2. Заполните `.env`

Минимум:

```env
BOT_TOKEN=...
ADMIN_IDS=123456789
ADMIN_PASSWORD=ваш_пароль
WEBAPP_URL=https://example.com
PAYMENT_PROVIDER=test
BOT_MODE=polling
HOST=0.0.0.0
PORT=8000
```

## 3. Проверьте 3 страницы

Откройте:
- `https://example.com/admin`
- `https://example.com/warehouse/`
- `https://example.com/download/android`

## 4. Зайдите в админку

Через `/admin`:
1. войдите по `ADMIN_PASSWORD`
2. смените тестовый пароль
3. укажите название магазина
4. проверьте контакты

## 5. Добавьте сотрудника склада

Через `/warehouse/`:
1. войдите как админ склада
2. откройте пользователей
3. создайте логин и пароль сотруднику

## 6. Добавьте тестовый товар

В `/warehouse/`:
1. нажмите `+`
2. укажите название
3. добавьте фото
4. укажите цену
5. укажите остаток
6. оставьте товар `на витрине`
7. сохраните

## 7. Установите APK

Файл:
- `telegram-shop/apk/Sklad-1.0.6-release.apk`

На телефоне:
1. установить APK
2. открыть приложение
3. ввести адрес сервера:

```text
https://example.com/warehouse/
```

## 8. Проверьте подключение APK

После входа сотрудника проверьте:
- список товаров открывается
- можно открыть карточку товара
- камера запрашивает доступ
- сканер работает
- при проблемах web scanner срабатывает native fallback

## 9. Если нужны облачные фото

В `/warehouse/` → `⚙ Настройки` → `Облако`:
1. выбрать S3
2. указать ключи и bucket
3. нажать `Проверить подключение`
4. нажать `Синхронизировать`
5. включить `Подтягивать фото с облака`

## 10. Готово

Если это всё работает, у вас уже есть:
- сервер
- склад
- витрина
- Android APK
- готовность к дальнейшей настройке облака, ИИ и автопостинга

Если нужен подробный вариант — смотрите `STEP-BY-STEP-RUNBOOK.md`.
