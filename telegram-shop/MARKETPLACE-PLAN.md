## 1. Позиционирование

**Слоган-идея:** «Свой маркетплейс: продавай проще, чем на Avito».
- Лёгкая регистрация (телефон → ключ → витрина за 2 минуты) — уже есть ✅
- Своя витрина у каждого продавца — уже есть ✅
- Комиссия площадки регулируется — уже есть ✅
- Никаких «проверок паспорта» и сложных кабинетов — только нужное
- Каналы продаж: сайт (SEO), Telegram (бот + Mini App), соцсети, Avito-фид

## 2. Что берём за образец (и что именно)

| Площадка | Что берём |

| **Ozon/WB** | Карточки с параметрами, бейджи скидок, рекомендации, товарные фиды |

## 3. Функциональные предложения (полный список)

### 3.1 Каталог, поиск, фильтры 🔨
- [x] **Подкатегории** (дерево: Электроника → Наушники → Беспроводные), ЧПУ-страницы, хлебные крошки, SEO-тексты на каждую
- [x] **Умный поиск**: опечатки («наушнеки» → наушники), синонимы (телефон/смартфон), поиск по описанию и параметрам, подсказки (autocomplete), недавние/популярные запросы
- [x] **Фильтры**: цена (от/до), состояние (новое/б/у/с дефектами), продавец, только с фото, только с торгом (флаг `negotiable`, блок 09); **сортировка**: дешевле/дороже/новые/по рейтингу продавца. Работают в API `/api/catalog` (с пагинацией `page/per_page/total/pages`), на SSR `/catalog` (форма фильтров) и в Mini App. Город/радиус и «наличие доставки» — не реализованы: у товаров и продавцов нет города в модели (см. гео-пункт ниже)
- [x] **Избранное** и «сравнить», сохранённые поиски с уведомлениями о новых объявлениях
- [ ] Карта с точками (ПВЗ/постаматы/продавцы рядом) — для гео-режима (не реализовано; требует город в модели продавца/товара)

### 3.2 Карточки товаров 🔨
- [x] **Фото-галерея до 10 фото** (свайп, зум, видео до 30 сек)
- [x] Поле **«Состояние»**: новое / как новое / хорошее / с дефектами + текстовый список дефектов
- [x] **Параметры** товара (бренд, размер, цвет, объём…) — произвольные пары ключ-значение: редактируются в кабинете продавца, участвуют в поиске и показываются в карточке. Шаблоны параметров по категориям — в бэктлоге
- [x] **Торг** (приём предложений цены): `/api/offers` — покупатель предлагает цену, продавец принимает/отклоняет/делает встречное (`countered`); флаг «можно поторговать» на товаре (блок 09). Бронь и «пожаловаться» — не сделаны (**блок 16**: reservation, complaints)
- [x] Кнопка «написать продавцу» → чат (Telegram-бот или чат внутри Mini App)
- [x] Бейджи: 🔥 топ, ⚡ можно забрать сегодня, 🚚 доставка 0 ₽

### 3.3 Продавцы и витрины 🔨
- [x] **Верификация**: статус `verification_status` (unverified/pending/verified/rejected), подача документов в кабинете, подтверждение админом (`POST /admin/api/sellers/{sid}/verify`), бейдж «проверенный продавец»
- [x] **Рейтинг и отзывы о продавцах** (после сделки), процент ответов, скорость ответа
- [ ] Подписка на витрину («любимые магазины»), лента новинок подписок — **блок 16** (Store subscriptions)
- [x] **Статистика продавца (базовая)**: товары, заказы, продажи, баланс, заработано — в кабинете. Просмотры витрины и конверсия — **блок 16** (Seller analytics)
- [x] **Тарифы витрин**: планы с лимитами объявлений/комиссией/холдом настраиваются в админке, лимит проверяется при создании товара (429). Биллинг/оплата тарифов — **блок 16**

### 3.4 Сделки и доверие 🔨
- [x] **Чат покупатель↔продавец** (`/api/chat/*`: треды, сообщения, непрочитанные, контекст объявления)
- [x] **Безопасная сделка (эскроу)**: при включённом холде средства попадают в `held_balance` продавца и автоматически размораживаются через `escrow_days` (`release_seller_held` + автorelease); комиссия только с успешной сделки
- [x] **Переговоры о цене**: встречное предложение продавца (`respond_to_offer: accepted/rejected/countered`)
- [ ] Жалобы, модерация (ручная + ИИ-скрининг запрещённого), чёрный список — **блок 16** (complaints, moderation, blacklist)
- [ ] Правила площадки, гарантии возврата, решение споров — нужны тексты оферты (юрист), вне кода

### 3.5 Оплата и доставка 🔨 (частично готово)

- [x] Холд средств (эскроу) для сделок: `held_balance` + авторазморозка `escrow_days` (см. 3.4)
- [ ] Печать этикеток/передача в службы доставки прямо из кабинета продавца — печать этикеток есть на складе (блок 03), передача из кабинета продавца не сделана

## 5. Метрики успеха
- Регистрации продавцов → активация (добавил 1+ товар) ≥ 60%
- Конверсия каталог → заказ ≥ 3–5%
- Доля повторных продавцов ≥ 50% за 90 дней
- GMV площадки, средняя комиссия, NPS покупателей и продавцов

## 7. Риски
- C2C требует модерации (жалобы, запрещённое) — решается ИИ + ручной контроль
- Безопасная сделка юридически чувствительна — проработать оферту (нужен юрист)
- Конкуренция с Avito/Юлой по трафику — компенсируем мессенджер-каналами и простотой
