# 🚀 ПЛАН: маркетплейс б/у вещей — «лёгкий Avito» — на согласование

> Дата: 20.08.2026 · Проект: Telegram Shop
> Цель: превратить текущую площадку в полноценный маркетплейс C2C/B2C для продажи
> б/у и новых вещей — проще и легче Avito, с упором на мессенджеры, SEO и соцсети.

## 1. Позиционирование

**Слоган-идея:** «Свой маркетплейс: продавай проще, чем на Avito».
- Лёгкая регистрация (телефон → ключ → витрина за 2 минуты) — уже есть ✅
- Своя витрина у каждого продавца — уже есть ✅
- Комиссия площадки регулируется — уже есть ✅
- Никаких «проверок паспорта» и сложных кабинетов — только нужное
- Каналы продаж: сайт (SEO), Telegram (бот + Mini App), соцсети, Avito-фид

## 2. Что берём за образец (и что именно)

| Площадка | Что берём |
|---|---|
| **Avito** | Категории/подкатегории, фильтры (цена/город/состояние), «Поднять объявление», VIP-выделение, рейтинг и отзывы о продавцах, безопасная сделка |
| **Юла** | Лёгкость C2C, встроенный чат покупатель↔продавец, торг/цена-предложение, гео-поиск «рядом со мной» |
| **Vinted** | Карточки б/у с **фото-галереей** (до 10 фото), состояние и дефекты, бренд/размер, холд средств до подтверждения получения |
| **Etsy** | Полноценные витрины продавцов, подписка на магазин, «любимые магазины» |
| **Ozon/WB** | Карточки с параметрами, бейджи скидок, рекомендации, товарные фиды |

## 3. Функциональные предложения (полный список)

### 3.1 Каталог, поиск, фильтры 🔨
- [x] **Подкатегории** (дерево: Электроника → Наушники → Беспроводные), ЧПУ-страницы, хлебные крошки, SEO-тексты на каждую
- [x] **Умный поиск**: опечатки («наушнеки» → наушники), синонимы (телефон/смартфон), поиск по описанию и параметрам, подсказки (autocomplete), недавние/популярные запросы
- [ ] **Фильтры**: цена (от/до + слайдер), состояние (новое/как новое/б/у), город/радиус, наличие доставки, продавец, только с фото, только с торгом; **сортировка**: дешевле/дороже/новые/по рейтингу
- [x] **Избранное** и «сравнить», сохранённые поиски с уведомлениями о новых объявлениях
- [ ] Карта с точками (ПВЗ/постаматы/продавцы рядом) — для гео-режима (не реализовано)

### 3.2 Карточки товаров ⏳
- [ ] **Фото-галерея до 10 фото** (свайп, зум, видео до 30 сек)
- [ ] Поле **«Состояние»**: новое / как новое / хорошее / с дефектами + текстовый список дефектов
- [ ] **Параметры** по категории (бренд, размер, цвет, объём, год выпуска…)
- [ ] Торг (приём предложений цены), бронь, «пожаловаться»
- [ ] Кнопка «написать продавцу» → чат (Telegram-бот или чат внутри Mini App)
- [ ] Бейджи: 🔥 топ, ⚡ можно забрать сегодня, 🚚 доставка 0 ₽

### 3.3 Продавцы и витрины ⏳
- [ ] **Верификация**: телефон + подтверждение; бейдж «проверенный продавец»
- [ ] **Рейтинг и отзывы о продавцах** (после сделки), процент ответов, скорость ответа
- [ ] Подписка на витрину («любимые магазины»), лента новинок подписок
- [ ] Статистика продавца: просмотры витрины, конверсия в заказ, топ товаров
- [ ] **Тарифы витрин**: бесплатный (до N объявлений) / «Магазин» / «Бизнес» (расширенные лимиты и продвижение)

### 3.4 Сделки и доверие ⏳
- [ ] **Чат покупатель↔продавец** (внутри Telegram-бота и Mini App; сообщения с контекстом объявления)
- [ ] **Безопасная сделка**: деньги замораживаются → покупатель подтверждает получение → средства продавцу; комиссия только с успешной сделки
- [ ] Переговоры о цене (встречное предложение продавца)
- [ ] Жалобы, модерация (ручная + ИИ-скрининг запрещённого), чёрный список
- [ ] Правила площадки, гарантии возврата, решение споров

### 3.5 Оплата и доставка 🔨 (частично готово)
- [x] Перевод по СБП/карте с подтверждением, CryptoBot, Stars; ЮKassa/Т-Банк — при ИП
- [x] Доставка: СДЭК, 5POST, Яндекс Доставка, курьер, почта, самовывоз
- [ ] Холд средств (эскроу) для C2C-сделок
- [ ] Печать этикеток/передача в службы доставки прямо из кабинета продавца
- [ ] Расчёт доставки по габаритам вводимым продавцом

### 3.6 Продвижение — площадка и продавцы ⏳
**Для всей системы (уже частично ✅):**
- [x] SEO: SSR-страницы, JSON-LD, sitemap, блог, FAQ-разметка
- [x] Фиды: Яндекс.Маркет, Google Merchant, Avito XML
- [x] Автопостинг новых товаров в Telegram-канал и VK

- [ ] Рекламные кабинеты: VK Ads и Яндекс.Директ — автозапуск по сгенерированным креативам
- [ ] Партнёрская программа (приведи продавца → % с его комиссии)

**Платные услуги для продавцов (монетизация):**

### 3.7 Дизайн-предложения ⏳
- [ ] **Mobile-first**: 80% трафика из мессенджеров; приложение-стиль, нижняя навигация, свайпы
- [ ] **PWA**: «установить на телефон», офлайн-каталог, push-уведомления о сообщениях и заказах
- [ ] Карточка-сетка с фото на всю ширину и бейджами (стиль Vinted/Avito-новый)
- [ ] Галерея фото с зумом и видео; тёмная тема

## 5. Метрики успеха
- Регистрации продавцов → активация (добавил 1+ товар) ≥ 60%
- Конверсия каталог → заказ ≥ 3–5%
- Доля повторных продавцов ≥ 50% за 90 дней
- GMV площадки, средняя комиссия, NPS покупателей и продавцов

## 7. Риски
- C2C требует модерации (жалобы, запрещённое) — решается ИИ + ручной контроль
- Безопасная сделка юридически чувствительна — проработать оферту (нужен юрист)
- Конкуренция с Avito/Юлой по трафику — компенсируем мессенджер-каналами и простотой
