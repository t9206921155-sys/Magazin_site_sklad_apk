# 🧾 Таблица «что куда вписывать»

Это единая практическая шпаргалка для владельца/админа: какие поля заполнять, где именно они находятся и что в них писать.

Если нужен пошаговый сценарий запуска, используйте вместе с:
- `FIRST-LAUNCH-15-MIN.md`
- `OWNER-ADMIN-SETUP.md`
- `STEP-BY-STEP-RUNBOOK.md`

## 1. Самый минимальный набор для старта

Без этого проект обычно не запускают в работу:

| Где | Поле | Что вписать | Пример |
|---|---|---|---|
| `telegram-shop/.env` | `BOT_TOKEN` | токен бота от BotFather | `123456:ABC...` |
| `telegram-shop/.env` | `ADMIN_IDS` | ваш Telegram ID | `123456789` |
| `telegram-shop/.env` | `ADMIN_PASSWORD` | пароль для `/admin` | `StrongPass123!` |
| `telegram-shop/.env` | `WEBAPP_URL` | публичный HTTPS-домен проекта | `https://shop.example.com` |
| `telegram-shop/.env` | `PAYMENT_PROVIDER` | платёжный режим на старте | `test` |
| `telegram-shop/.env` | `BOT_MODE` | режим бота | `polling` |
| `telegram-shop/.env` | `HOST` | адрес bind веб-сервера | `0.0.0.0` |
| `telegram-shop/.env` | `PORT` | порт приложения | `8000` |
| `/warehouse/` в APK | адрес склада | адрес мобильного склада | `https://shop.example.com/warehouse/` |

## 2. `.env` — exact поля и что в них писать

Файл: `telegram-shop/.env`

| Поле | Обязательно | Что это | Что вписывать | Пример |
|---|---|---|---|---|
| `BOT_TOKEN` | Да | токен Telegram-бота | токен из BotFather | `1234567890:AA...` |
| `ADMIN_IDS` | Да | Telegram ID админов | один или несколько ID через запятую | `123456789,987654321` |
| `ADMIN_PASSWORD` | Да | пароль входа в `/admin` | новый сильный пароль | `StrongPass123!` |
| `WEBAPP_URL` | Да для production | публичный URL сайта | HTTPS-домен без `/admin` и без `/warehouse/` | `https://shop.example.com` |
| `PAYMENT_PROVIDER` | Да | платёжный режим по умолчанию | `test`, потом `yookassa`, `tbank`, `cryptobot` или `stars` | `test` |
| `BOT_MODE` | Да | способ запуска бота | `polling` для быстрого старта, `webhook` для production | `polling` |
| `WEBHOOK_PATH` | Нет | путь webhook | нужен только если включаете webhook | `/tg/webhook` |
| `WEBHOOK_SECRET` | Нет | секрет webhook | случайная длинная строка | `change_me_secret` |
| `HOST` | Да | host приложения | почти всегда `0.0.0.0` | `0.0.0.0` |
| `PORT` | Да | порт приложения | порт FastAPI/сайта | `8000` |

## 3. `/admin` — основные поля владельца

Раздел: `/admin`

### 3.1 ИИ

| Поле в интерфейсе | Где | Что вписать | Пример |
|---|---|---|---|
| `Включить ИИ` | `/admin` → Настройки | включить, если будете генерировать тексты | `ON` |
| `API-ключ (пусто = не менять)` | `/admin` → Настройки → ИИ | ключ провайдера OpenAI-compatible API | `sk-...` |
| `Base URL` | `/admin` → Настройки → ИИ | базовый API URL провайдера | `https://api.openai.com/v1` |
| `Модель` | `/admin` → Настройки → ИИ | имя модели | `gpt-4o-mini` |
| `Tavily API-ключ (поиск аналогов в интернете)` | `/admin` → Настройки → ИИ | ключ Tavily, если нужен поиск аналогов | `tvly-...` |

## 4. `/warehouse/` → `⚙ Настройки` → `Облако`

### 4.1 S3-совместимое хранилище

| Поле в интерфейсе | Что вписать | Пример |
|---|---|---|
| `Использовать облако` | включить облачное хранение фото/резерва | `ON` |
| `S3-совместимое (Selectel / Cloud.ru / VK Cloud / Яндекс / MinIO)` | выбрать тип подключения | `S3` |
| `Provider / Preset` | провайдер из списка | `Selectel` |
| `Endpoint (пусто = из пресета)` | endpoint S3, если не подставился автоматически | `s3.ru-1.storage.selcloud.ru` |
| `Access Key` | access key S3 | `AKIA...` |
| `Secret Key (пусто = не менять)` | secret key S3 | `secret...` |
| `Bucket` | имя bucket | `shop-photos` |
| `Регион (пусто = из пресета)` | регион S3 | `ru-1` |
| `Подтягивать фото с облака (CDN-URL, быстрее загрузка)` | включить CDN-URL после синхронизации | `ON` |
| `Автосинхронизация фото при сохранении товара` | включить автоотправку новых фото в S3 | `ON` |

### После заполнения S3

Нажать по порядку:
1. `Проверить`
2. `Синхронизировать`
3. при необходимости `⬇️ Из облака`

### 4.2 MySQL / MariaDB

| Поле в интерфейсе | Что вписать | Пример |
|---|---|---|
| `Хост (mysql.example.com)` | адрес сервера БД | `db.example.com` |
| `Порт 3306` | порт MySQL | `3306` |
| `Пользователь` | логин БД | `shop_user` |
| `Пароль (пусто = не менять)` | пароль БД | `db_password` |
| `База (shop)` | имя базы | `shop` |
| `Таблица (products)` | таблица каталога | `products` |

### 4.3 Supabase

| Поле в интерфейсе | Что вписать | Пример |

## 5. Что писать сотруднику для APK

| Где | Поле | Что дать сотруднику | Пример |
|---|---|---|---|
| Android APK | файл установки | APK-файл склада | `telegram-shop/apk/Sklad-1.0.5-release.apk` |
| Первый экран приложения | адрес сервера | URL склада с `/warehouse/` на конце | `https://shop.example.com/warehouse/` |
| Вход в приложение | логин | логин сотрудника | `worker1` |
| Вход в приложение | пароль | пароль сотрудника | `StrongWorkerPass1` |
| Альтернатива ручному вводу | deep link | быстрая ссылка подключения | `sklad://connect?url=https://shop.example.com/warehouse/` |

## 6. Где зарегистрировать S3

Если вам нужен самый простой практический вариант, начните с **Selectel**.

| Провайдер | Для чего подходит | Где регистрироваться |
|---|---|---|
| Selectel | самый прямой старт для S3 в текущем проекте | `https://my.selectel.ru/registration` |
| VK Cloud | тоже подходит для S3 bucket + keys | `https://cloud.vk.ru/` |
| Yandex Cloud Object Storage | если уже есть аккаунт Yandex Cloud | `https://console.yandex.cloud/` |
| Cloud.ru | если хотите Object Storage в Cloud.ru | `https://cloud.ru/` |
| MinIO | если хотите свой S3 на своём сервере | разворачивается самостоятельно |

### Что нужно получить после регистрации S3

Обязательно сохраните:
- `Access Key`
- `Secret Key`
- `Bucket`
- `Endpoint`
- `Region`

Именно эти поля потом нужно внести в `/warehouse/` → `⚙ Настройки` → `Облако`.

## 7. Рекомендуемый практический порядок

1. Заполнить `.env`
2. Задеплоить проект
3. Открыть `/admin`
4. Открыть `/warehouse/`
5. Добавить сотрудника
6. Подключить APK
7. Подключить S3
8. Нажать `Проверить` и `Синхронизировать`
9. Включить `Подтягивать фото с облака`
10. Потом уже настраивать AI, VK, Avito, оплату и RuStore
