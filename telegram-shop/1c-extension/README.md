# Расширение 1С: «тгОбменСМагазином» — обмен с магазином Telegram

Двусторонний обмен между базой 1С и магазином (Telegram-бот + сайт):

| Направление | Что делает |
|---|---|
| 1С → магазин | Выгружает номенклатуру (код, наименование, цену из регистра цен, категорию, фото) в каталог магазина |
| магазин → 1С | Загружает оплаченные заказы и создаёт документы заказа с табличной частью, контрагентом и комментарием |
| 1С → магазин | Передаёт статус «отправлен», когда документ проведён |

Расширение **не меняет структуру вашей конфигурации**: все объекты (справочники,
документы, регистры) находятся по именам, которые вы указываете в настройках
обработки. Подходит для типовых конфигураций: УТ 11, УНФ, КА 2, БП 3.0 и др.

---

## Состав папки

```
тгОбменСМагазином/                     ← выгрузка расширения в файлы (XML + BSL)
├── Configuration.xml
├── InformationRegisters/тгНастройкиОбмена.xml
├── CommonModules/тгОбменСМагазином.xml
│   └── Ext/Module.bsl                 ← основной код обмена
├── CommonCommands/тгОткрытьОбменСМагазином.xml
│   └── Ext/CommandModule.bsl
└── DataProcessors/тгОбменСМагазином.xml
    └── Forms/Форма/Ext/Form.xml + Form/Module.bsl

modules/                               ← те же тексты модулей отдельно (для ручной сборки)
```

## Способ 1. Загрузка готового расширения (Конфигуратор)

1. Конфигуратор → **Конфигурация → Расширения конфигурации**.
2. Нажмите **«Добавить»**, выберите пункт «Из файла» / «Загрузить из файлов».
3. Укажите корневую папку `тгОбменСМагазином/` (ту, где лежит `Configuration.xml`).
4. Обновите конфигурацию базы данных (F7) и включите расширение
   (Предприятие → Все функции → Расширения конфигурации).

> Формат выгрузки зависит от версии платформы. Если платформа сообщит об ошибке
> формата — используйте Способ 2 (15 минут, все тексты уже готовы).

## Способ 2. Ручная сборка (надёжно для любой платформы 8.3.14+)

Все тексты модулей лежат в папке `modules/` — их нужно просто вставить.

1. **Расширение**: Конфигуратор → Конфигурация → Расширения конфигурации → Добавить →
   имя `тгОбменСМагазином`, префикс `тг`.
2. **Регистр сведений «тгНастройкиОбмена»** (внутри расширения):
   непериодический, режим записи — независимый.
   Измерение `Ключ` — Строка(100). Ресурс `Значение` — Строка(0).
3. **Общий модуль «тгОбменСМагазином»**: флажки — Сервер, Вызов сервера, Привилегированный.
   Вставьте код из `modules/тгОбменСМагазином.bsl`.
4. **Обработка «тгОбменСМагазином»** с формой «Форма»:
   - реквизиты формы (тип Строка): `АдресМагазина` (500), `Токен1С` (150),
     `СправочникНоменклатуры` (100), `ДокументЗаказ` (100), `СправочникКонтрагенты` (100),
     `ТЧТовары` (100), `РегистрЦен` (100), `РеквизитВнешнийНомер` (100),
     `Журнал` (Строка неогр. длины, многострочное поле);
   - команды формы: `ВыгрузитьКаталог`, `ЗагрузитьЗаказы`, `ОтметитьОтгруженные`,
     `СохранитьНастройки`, `ОчиститьЖурнал`;
   - элементы формы: поля реквизитов + кнопки с командами + многострочный «Журнал»
     (расположение любое; образец — в `DataProcessors/тгОбменСМагазином/Forms/Форма/Ext/Form.xml`);
   - в модуль формы вставьте код из `modules/МодульФормы.bsl`.
5. **Общая команда «тгОткрытьОбменСМагазином»** — модуль команды из `modules/ОбщаяКоманда.bsl`.
   Разместите команду в разделе команд интерфейса (например, «Сервис»).
6. Обновите базу (F7) и включите расширение.

## Настройка обмена (один раз)

1. В магазине: **/admin → Импорт и 1С** → скопируйте токен 1С.
2. В 1С откройте «Обмен с магазином Telegram» (команда в разделе «Сервис»).
3. Заполните:
   - **Адрес магазина** — https-адрес сайта (например `https://shop.example.com`);
   - **Токен 1С** — из админ-панели магазина;
   - Соответствия: справочник номенклатуры (обычно `Номенклатура`), документ заказа
     (УТ/УНФ: `ЗаказКлиента`; БП: `РеализацияТоваровУслуг`), контрагенты (`Контрагенты`),
     табличная часть (`Товары`), регистр цен (`ЦеныНоменклатуры` — пусто, если цены
     в магазине ведёте сами), реквизит для номера заказа (пусто, если такого нет).
4. Нажмите «Сохранить настройки».

## Работа

- **«Выгрузить каталог в магазин»** — 1С → магазин. Товары сопоставляются по артикулу
  (коду); новые создаются, существующие обновляются (цена, описание, категория, фото).
- **«Загрузить заказы из магазина»** — магазин → 1С. По каждому оплаченному заказу
  создаётся и проводится документ: контрагент (ищется по телефону или создаётся),
  строки с номенклатурой, количеством, ценой, суммой; контакты и адрес — в комментарии.
  После выгрузки магазин получает подтверждение (заказ помечается «выгружен в 1С»).
- **«Передать статусы отгрузки»** — 1С → магазин. Проведённые документы заказов
  переводят заказ в магазине в статус «отправлен» (клиент получает уведомление в Telegram).

## API магазина (заголовок `X-1C-Token`)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/1c/catalog` | товары магазина |
| POST | `/1c/catalog` | выгрузка каталога из 1С |
| GET | `/1c/orders?synced=0&status=paid,processing,shipped` | новые заказы |
| POST | `/1c/orders/ack` | подтверждение выгрузки `{"ids":["ORD-1001"]}` |
| POST | `/1c/orders/status` | статус из 1С `{"id":"ORD-1001","status":"shipped"}` |

Токен можно перевыпустить в админке (Импорт и 1С → «Сбросить»).

## Требования

- Платформа 1С:Предприятие 8.3.14+ (расширения, HTTP-соединения, JSON).
- HTTPS-доступ к магазину из сети 1С.
- Права на чтение/запись объектов обмена (модуль выполняется привилегированно).
