## ✅ Уже сделано (этап 0)

### Сайт
- Современный продающий дизайн: hero-блок, преимущества, карточки с бейджами/скидками,
  анимации, полностью адаптивный (десктоп/планшет/мобильный, мобильное меню)
- Семантическая разметка HTML5, скорость: lazy-load картинок, системные шрифты, без тяжёлых библиотек
- SSR-страницы для поисковиков: `/` (главная), `/catalog` (каталог с фильтрами), `/p/{id}` (карточка)

### SEO
- Уникальные title/description для каждой страницы (шаблон «{товар} — {цена} ₽ — {магазин}»)
- Open Graph + Twitter Cards (превью в соцсетях), OG-картинки товаров и главной
- JSON-LD: Organization/OnlineStore, Product (цена, наличие, SKU), BreadcrumbList
- `sitemap.xml` (автоматический из каталога) и `robots.txt`
- Canonical URL, noindex для служебных страниц приложения
- SEO-тексты на главной и в категориях (правятся в админке)

### Рекомендации
- «Похожие товары» (та же категория), «С этим также покупают» (анализ заказов),
  «Популярное в магазине» (лидеры продаж), «Вы недавно смотрели» (локальная история)

### ИИ
- Модуль ИИ (OpenAI-совместимый API: OpenAI/DeepSeek/OpenRouter и др.):
  - генерация продающего описания + SEO-заголовка + meta description
  - генерация рекламы: пост для соцсетей, хештеги, слоган, сценарий видеоролика
  - поиск аналогичных товаров в интернете (Tavily API; без ключа — ссылки на
    Яндекс.Маркет/Ozon/WB/AliExpress по сгенерированному запросу)
- Кнопки ИИ прямо в карточке товара в админке
- Автогенерация баннеров (1080×1080 и OG 1200×628) с фото, ценой, скидкой — локально
- Автогенерация видеороликов 1080×1080 (зум, титры, цена) — локально, без внешних API

### Автопостинг
- Telegram-канал: фото + описание + цена (бот должен быть админом канала)
- VK: публикация в группу с фото (access token + id группы)
- Автопостинг при создании товара (включается переключателем в админке)

### Avito
- **REST API**: создание/обновление/закрытие объявлений (client_id + client_secret из кабинета),
  кнопки «📌 Avito»/«🔄 Avito»/«✕ Avito» у каждого товара, пакетная выгрузка каталога
- **Автозагрузка по XML-фиду**: `/avito/autoload.xml?key=…` — Avito сам забирает каталог
  по расписанию (API-заявка не нужна)
- Статус объявления и ссылка хранятся в карточке товара
